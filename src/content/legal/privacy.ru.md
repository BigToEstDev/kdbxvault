Редакция от 17 ноября 2026 г.

KDBX Vault — офлайн-менеджер паролей. Эта политика касается приложения (Android и ПК) и этого сайта.

## Приложение

- Приложение работает только на вашем устройстве. Ваши базы, пароли и ключевые файлы никогда не отправляются нам
  или кому-либо ещё: серверов и аккаунтов нет.
- Без сети: у Android-приложения нет разрешения на интернет, приложение для ПК не подключается к интернету. Ссылка
  (сайт, исходный код, issues) открывается в браузере, только когда вы сами её выбираете.
- Без аналитики, рекламы, отчётов о сбоях и телеметрии.
- База — файл, который выбираете вы. Приложение читает и записывает только выбранные вами файлы: базу, ключевые
  файлы, вложения, копии для синхронизации.
- На устройстве приложение хранит свои настройки и список недавно открытых баз. При разблокировке по биометрии на
  Android пароль базы хранится зашифрованным ключом Android Keystore, который не покидает устройство. Данные
  приложения не попадают в облачные резервные копии.

## Сайт

- Статический сайт на GitHub Pages: без аналитики, без cookies, без сторонних ресурсов.
- Выбранные язык и тема хранятся в вашем браузере (local storage) и никуда не отправляются.
- GitHub как хостинг может записывать технические данные запросов, например IP-адреса, — см.
  [GitHub Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
- Файлы скачиваются с GitHub Releases; мы видим только общее число скачиваний.
